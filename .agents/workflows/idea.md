---
description: Clarify and refine a rough idea before specification or implementation
---

Use `interview-me` when intent, users, outcomes, constraints, or success criteria are unclear. Ask one question at a time and require confirmation.

Once the problem is understood, use `idea-refine`. Inspect relevant repository constraints, compare meaningful alternatives, and recommend one direction with an MVP, exclusions, assumptions, and open questions.

Do not write production code or create `SPEC.md`. Return the confirmed direction and stop for user approval.
